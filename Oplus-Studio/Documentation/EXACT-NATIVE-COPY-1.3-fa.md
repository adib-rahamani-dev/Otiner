# ذخیره دقیق Native در Otiner Studio 1.3

نسخه 1.3 برای هر Asset دو نسخه نگه می‌دارد:

- `native.aep`: کپی Native خود After Effects برای حفظ دقیق Shape، Stroke، Gradient، Text، Mask، Keyframe، Expression و وضعیت داخلی افکت‌ها.
- `data.json`: نسخه قابل‌بررسی و جایگزین برای سازگاری و بازیابی.

## روش ذخیره

1. پروژه After Effects را حداقل یک بار Save کنید.
2. لایه‌های موردنظر را انتخاب کنید.
3. در Otiner روی `SAVE` بزنید.
4. نام Asset را وارد کنید و `SAVE ASSET` را بزنید.
5. Otiner پروژه فعلی را Save می‌کند، یک پروژه کوچک `native.aep` از لایه‌ها و وابستگی‌هایشان می‌سازد و پروژه اصلی را خودکار دوباره باز می‌کند.

اگر پروژه هنوز Save نشده باشد، Otiner عملیات را متوقف می‌کند تا هیچ پروژه‌ای از دست نرود.

## افکت‌های جانبی مثل Deep Glow

- اگر همان پلاگین روی سیستم مقصد نصب باشد، لایه با وضعیت Native و تنظیمات داخلی همان افکت کپی می‌شود.
- اگر پلاگین نصب نباشد، Otiner آن افکت را وارد نمی‌کند و هشدار `EFFECT_NOT_INSTALLED` برمی‌گرداند.
- سایر بخش‌های سالم لایه همچنان وارد می‌شوند.

## Share

`SHARE ASSET` فایل‌های `native.aep`، `data.json`، تصویر Preview و Mediaهای وابسته را در یک ZIP قرار می‌دهد. Mediaها با اندازه و SHA-256 بررسی می‌شوند.

طرف مقابل از دکمه `ADD ASSET` بسته را وارد Library می‌کند و سپس روی `IMPORT` می‌زند.

## محدودیت واقعی

فونت یا پلاگین تجاری داخل بسته کپی نمی‌شود. خود فونت و خود پلاگین باید روی سیستم مقصد نصب باشند. فقط تنظیمات و وضعیت لایه ذخیره می‌شود.
