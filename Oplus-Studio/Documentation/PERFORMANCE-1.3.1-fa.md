# بهینه‌سازی Save و Load در Otiner Studio 1.3.1

در این نسخه هیچ Property، Keyframe، Expression، Shape، Stroke، Text، Effect، پلاگین یا فایل Media حذف و ساده‌سازی نمی‌شود. فایل `native.aep` همچنان مرجع اصلی Exact Copy است و `data.json` کامل نیز به‌عنوان مسیر سازگاری ذخیره می‌شود.

## Save سریع و امن

- لایه‌های انتخاب‌شده و وابستگی‌های Parent، Track Matte و Layer Control با Copy/Paste داخلی خود After Effects وارد یک پروژه موقت و کوچک می‌شوند.
- کل پروژه اصلی دیگر برای مسیر عادی `Reduce Project` نمی‌شود؛ بنابراین پروژه‌های بزرگ فشار بسیار کمتری تحمل می‌کنند.
- قبل از شروع، پروژه اصلی روی دیسک Save می‌شود و همه تغییرات موقت هنگام بستن پروژه دور ریخته می‌شوند.
- اگر مسیر سریع روی یک نسخه یا زبان خاص After Effects در دسترس نباشد، Otiner خودکار به مسیر دقیق قبلی برمی‌گردد و Asset ناقص تحویل نمی‌دهد.

## Load سریع‌تر

- اولین Load، فایل `native.aep` را به‌صورت کامل Import می‌کند.
- Loadهای بعدی همان Asset در همان پروژه از Cache معتبر داخل پروژه استفاده می‌کنند.
- Cache با مسیر، اندازه و زمان تغییر فایل AEP کنترل می‌شود؛ بنابراین بعد از Update شدن Asset، نسخه قدیمی به اشتباه استفاده نمی‌شود.

## Media بدون فشار زیاد به RAM

- فایل‌های بزرگ و Image Sequenceها در بلوک‌های 4MB خوانده می‌شوند.
- Copy و محاسبه SHA-256 در یک مرحله انجام می‌شود.
- فایل کامل دیگر برای Hash داخل RAM قرار نمی‌گیرد؛ در نتیجه احتمال Freeze یا کمبود حافظه برای Footageهای بزرگ کمتر است.

## محافظت در برابر تداخل

در زمان Save، Reopen و Import، بررسی دوره‌ای وضعیت پنل موقتاً متوقف می‌شود تا چند دستور `evalScript` هم‌زمان به After Effects ارسال نشود.
